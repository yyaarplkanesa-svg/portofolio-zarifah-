# Portfolio — versi mirip video referensi

Project ini dibuat ulang berdasarkan struktur visual video yang kamu kirim:
- Background ruang angkasa + bintang
- Intro/loading screen
- Navbar pill di bagian atas
- Hero "Turning Ideas Into Reality"
- Kartu Daily Rotation
- About Me dengan visual portrait
- Education & Experience
- Statistik
- Tab Projects / Certificates / Awards / Tech Stack
- Contact form
- Responsive untuk HP dan desktop

## Jalankan di VS Code
1. Extract ZIP.
2. Buka folder ini di VS Code.
3. Buka `index.html`.
4. Gunakan Live Server atau buka langsung di browser.

## Edit data kamu
Semua data utama ada di `index.html`.
Cari dan ganti:
- `Zarr`
- deskripsi
- universitas/sekolah
- experience
- project
- certificate
- email
- link sosial media

## Catatan
Visual portrait dibuat dengan CSS supaya project langsung jalan tanpa gambar eksternal.
Kalau kamu punya foto sendiri, bagian `.portrait` bisa diganti dengan `<img src="assets/foto-kamu.png">`.
